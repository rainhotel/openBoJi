## 统一样例数据

所有日期按 Asia/Shanghai。当前演示时点为 2026-10-18 周日 19:41；本周为 10/12–10/18，下周为 10/19–10/25。

- 运动目标：每周 3 次，每次至少 20 分钟，按不同自然日计次。用户自定，非健康建议。
- 本周训练事实：10/14 45 分钟、10/18 40 分钟，共 85 分钟，2/3 次。
- 学习目标：每周 90 分钟。10/13 项目学习 45 分钟、10/18 Redis 30 分钟，共 75/90 分钟。
- 今天未来安排：20:30–20:55 整理项目下一步；在当前时点尚未完成，不提前纳入学习时长。
- 今天已确认晚饭支出 ¥28，不参与训练与学习的打卡分母。
- 15 展示第二次训练保存前的预览时刻：45 → 85 分钟，运动 1/3 → 2/3；13/14/21 是保存后的状态。
- 16/17/18 是学习记录集合的不同查看方式：只有两条事实，合计 75 分钟。
- 21 标“本周进行中”；本周期结束前不把 2/3 定性为最终失败。
- 19/20 是下周规划演示。周三 10/21 训练改到周四 10/22，仅改变计划，不增减实际运动次数。

## 路径一：安排 → 完成 → 自动计入目标

1. 在周目标中选“安排一次”，挑日期时间，生成单次安排。
2. 到时开始，结束后填写或确认实际完成量。
3. 系统根据明确关联，展示将更新的目标与周期。
4. 保存一条真实记录并关联安排；习惯、日历和目标同步引用。
5. 在习惯页再点同一次记录，查看详情；不重复新增一次打卡。

如果用户直接说“刚练完 40 分钟”，允许绕过预先安排：保存事实，关联目标；不伪造过去的计划。

## 路径二：补记与部分完成

用户周日补记周三 45 分钟：发生日期为周三，录入时间为周日。确认前提示当周统计会改变。用户只知道“周三”时解析到具体日期并展示，不默认填某个开始时间。

用户只练了 15 分钟，低于其自定 20 分钟阈值：事实保存 15 分钟并可显示“本次未计入次数”，不把次数强制加 1；用户可以修改错误时长，但不能为了达标悄悄改阈值。阈值变更范围见方案。

## 路径三：从记录到多个视图

16 点 Redis → 17 看实际 30 分钟、学习目标、所属项目与原始输入 → 返回表格 → 18 设置本周学习筛选 → 保存视图。

视图删除仅删显示配置；记录删除要另行确认关联影响。表格改实际时长会重算目标，不能只改屏幕数字。统计字段只读，通过编辑来源记录修正。

18 中“今天或本周”基于实际发生日期，跟随规则时区；不误用录入日期。时间轴视图只能绑定可编辑的计划日期；不能把创建时间当成可拖动计划。

## 路径四：周内改期

19 选择下周三训练 → 改时间 → 20 显示 10/21 19:00 → 10/22 19:00，以及以下范围：仅这一次 / 本次及以后 / 整个系列（保留历史）。

默认仅这一次。若选择系列范围，必须重新列出受影响的未来项；若本周目标量、可用时段或版本发生变化，重新核查。改期未跨周期时不改变本周额度；跨周期时明确显示原周期和新周期影响，并保留实例身份，不能在两周重复计算同一事实。

## 手机交互补充

- 拖动提供长按反馈，但始终有“改日期/时间”按钮；记录事实不允许通过拖动误变成计划。
- 表格优先三到四列，标题/名称列固定；详细字段在抽屉中编辑，宽表可横向查看，不能和主页面返回手势争夺同一操作区。
- 每个视图保留筛选标识和清除入口；不把“没有记录”与“当前筛选没有结果”混淆。
- 新建记录在当前筛选外仍可保存，提示查看；不自动往财务、训练事实补入不符合实际的筛选默认值。
- 输入时提供数字/时间适配键盘、明确单位与日期，常用字段留在一屏，附加字段折叠。
- 表格横向滚动、拖动改期、日历切换都需要真机与大字体验证；静态图不证明可操作性。

## 设计评审与后续验收矩阵

以下尚未在应用执行，作为未来验收条件：

| 场景 | 预期 |
| --- | --- |
| 同一训练从日历与习惯页重复打开 | 仍是一条记录、一次计数 |
| 一天两次符合条件的训练 | 时长全部保存，默认天频次只计一次 |
| 两条训练记录分别关联同一目标 | 周期按各自实际日期和计数规则汇总 |
| 学习完成 20+10 分钟 | 显示 30 分钟，不强行生成两次日打卡 |
| 周运动目标尚无具体日期 | 待安排显示额度，日历不出现七条逾期 |
| 周日晚周期尚未结束 | 显示进行中及现有完成量 |
| 修改以后每周目标 | 过去周期结果保持当时的规则口径 |
| 补记上周 | 仅改变对应实际周期，保留补记标识 |
| 跨周改期后离线重启 | 单次实例不重复展开，周期归属明确 |
| 从学习表格删视图 | 事实和目标关联仍存在 |
| 保存记录后不满足当前过滤 | 显示保存成功和查看入口，而非伪装写入失败 |
| 目标归档 | 历史训练、账单和学习保留 |
| 无原始记录却点击“已储蓄” | 不生成资金转账，提示明确目标记录方式 |
| 财务权限排除、请求综合复盘 | AI 只看已授权范围，缺失财务数据时不推断 |
| 离线一周、重启、再联网 | 基础记录和统计正常；AI队列遵守原授权 |

这轮仅校验设计文件可打开、图面内容与示例数字一致；交互、性能、可达性和统计正确性均需未来工程验证。
